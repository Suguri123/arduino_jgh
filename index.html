1차시 아두이노 기초 및 LED 제어

1차시 주요 장치/개념 설명

• 아두이노 우노 (Arduino UNO)

이탈리아에서 개발된 오픈소스 기반 단일 보드 마이크로컨트롤러입니다. C/C++ 기반의 스케치 언어를 사용하여 센서 입력을 받고 모터/LED 등의 출력 장치를 제어합니다.

• 브레드보드 (Breadboard)

납땜 없이 회로를 구성하는 도구입니다. 바깥쪽 파란선(-)과 빨간선(+)은 세로로 연결되어 전원 버스로 쓰이고, 안쪽 구멍들은 가로 5칸씩 내부적으로 연결되어 부품 간 회로를 이어줍니다.

• 저항 (Resistor)

전류의 흐름을 방해하여 회로를 보호하는 소자입니다. LED는 5V 전압을 직접 받으면 과전류로 탈 수 있어 220Ω(적적갈금) 저항을 사용해 전류량을 안전하게 낮춰주어야 합니다.

• 발광 다이오드 (LED)

순방향 전압을 걸었을 때 빛을 내는 반도체 소자입니다. 극성이 존재하여 다리가 긴 쪽이 양극(Anode, +), 다리가 짧고 평평한 쪽이 음극(Cathode, -)입니다. 반대로 꽂으면 켜지지 않습니다.

아두이노 IDE 설치 방법

  • 1. 아두이노 공식 소프트웨어 다운로드 페이지에 접속합니다.
  • [아두이노 공식 다운로드 페이지]
  • 2. 사용 중인 OS 환경에 맞는 설치 파일(Windows Win 10 and newer, macOS 등)을 선택해 다운로드합니다.
  • 3. 기부 안내 창이 뜨면 'Just Download' 버튼을 클릭하여 무료로 다운로드를 진행합니다.
  • 4. 다운로드된 설치 프로그램(.exe 등)을 실행하여 기본 설정대로 설치를 완료합니다.

개발 환경 구축 및 포트 설정

  • 1. PC와 아두이노 우노(UNO) 보드를 USB 케이블로 연결합니다.
  • 2. 아두이노 IDE 상단 메뉴의 [도구] → [보드] → [Arduino Uno]를 차례로 선택합니다.
  • 3. [도구] → [포트] 메뉴에서 인식된 [COM포트 번호]를 선택합니다.
  • 4. 보드 인식이 안 되는 호환 제품의 경우 전용 통신 칩셋인 CH340 드라이버를 꼭 추가 설치해야 정상 인식됩니다.
실습 1: 7번 디지털 핀에 LED 연결 후 1초 간격 토글(점멸) Digital Write
회로 결선 안내:
  • • 아두이노 7번 핀 → 220옴 저항
  • • 저항 → LED 긴 다리 (Anode, +극)
  • • LED 짧은 다리 (Cathode, -극) → 아두이노 GND
저항을 생략할 경우 과전류로 인해 LED 수명이 급감하거나 손상되므로 반드시 220Ω 저항을 사용해 주세요.
Sketch Code 
// [1차시 기본 예제] 디지털 출력 제어로 LED 깜빡이기
void setup() {
  pinMode(7, OUTPUT); // 7번 디지털 핀을 출력(OUTPUT) 모드로 설정 (전류를 보낼 준비를 함)
}

void loop() {
  digitalWrite(7, HIGH); // 7번 핀에 5V(HIGH) 전압을 출력하여 LED를 켬
  delay(1000);           // 1000ms(1초) 동안 프로그램을 멈추고 현재 상태(켜짐)를 유지

  digitalWrite(7, LOW);  // 7번 핀에 0V(LOW) 전압을 출력하여 LED를 끔
  delay(1000);           // 대기 (1초)
}

2차시 RGB LED, 조도센서, 스위치 & 부저

2차시 주요 장치/개념 설명

• RGB LED

빨강(R), 초록(G), 파랑(B) 세 가지 색상의 LED가 패키징된 소자입니다. 아두이노의 아날로그 PWM 핀을 연결하여 빛의 세기를 0~255 단계로 조합하면 보라색, 노란색 등 천만 가지의 다채로운 색을 직접 만들어낼 수 있습니다.

• 조도센서 (Cds)

황화카드뮴(Cds)을 사용하여 빛의 밝기를 감지하는 반도체 센서입니다. 빛의 세기가 강할수록 저항값이 작아져 전압이 변하며 아두이노 아날로그 핀(A0~A5)을 통해 0(아주 어두움)~1023(아주 밝음)의 전압 디지털 값으로 리딩합니다.

• 택트 스위치와 풀업저항

물리적으로 회로를 끊거나 이어주는 소자입니다. 스위치가 떨어져 있을 때 전위가 불완전해져 0과 1사이를 떠도는 플로팅(Floating) 현상을 예방하기 위해 내장 풀업 저항(`INPUT_PULLUP`)을 설정하여 평소엔 1, 버튼이 눌리면 0(LOW)을 읽어냅니다.

• 부저 (Buzzer)

전류를 흘려 소리를 발생시키는 소자입니다. 내부 발진 회로가 있어 전원만 넣으면 단음이 나는 능동 부저(Active)와 발진 회로가 없어 아두이노의 `tone()` 함수를 이용해 주파수 신호를 주어야 다양한 음계를 연주할 수 있는 수동 부저(Passive)가 있습니다.

PWM (펄스 폭 변조)

디지털 신호로 아날로그 출력을 흉내 내는 기술. 밝기나 전압 레벨을 0(완전 오프)부터 255(완전 온)까지 세밀하게 제어할 수 있습니다.

내부 풀업 저항

플로팅 현상(전압이 떠 있는 불안정한 상태)을 막기 위해 아두이노 내장 저항을 통해 풀업 상태로 고정. 스위치를 누르면 LOW 신호가 입력됩니다.

🚩 실습2 : 7, 8, 9번에 연결된 LED에 1초씩 순차적으로 불 켜기 (미션1)

Sequential Blink

동작 목표:

  • 1초 동안 7번 핀만 켜지고 나머지 핀은 꺼집니다.
  • 다음 1초 동안 8번 핀만 켜지고 나머지는 꺼집니다.
  • 마지막 1초 동안 9번 핀만 켜지고 나머지는 꺼집니다.
Mission1.ino 
void setup()
{
  pinMode(7, OUTPUT);  // 빨간 LED
  pinMode(8, OUTPUT);  // 노란 LED
  pinMode(9, OUTPUT);  // 초록 LED
}

void loop()
{
  // 7번 LED ON, 나머지 OFF
  digitalWrite(7, HIGH);
  digitalWrite(8, LOW);
  digitalWrite(9, LOW);
  delay(1000);

  // 8번 LED ON, 나머지 OFF
  digitalWrite(7, LOW);
  digitalWrite(8, HIGH);
  digitalWrite(9, LOW);
  delay(1000);

  // 9번 LED ON, 나머지 OFF
  digitalWrite(7, LOW);
  digitalWrite(8, LOW);
  digitalWrite(9, HIGH);
  delay(1000);
}

3차시 서보모터·DC모터를 활용한 출력장치 제어

3차시 주요 장치/개념 설명

• 초음파 거리센서 (HC-SR04)

약 40kHz의 초음파를 순간적으로 보낸 뒤 장애물에 부딪혀 되돌아오는 시간(Echo)을 측정하여 물체와의 거리를 구합니다. 소리의 전파속도(340m/s)를 기반으로 하여 `거리 = (왕복 시간 * 0.034) / 2` 계산 공식이 성립합니다.

• 서보모터 (SG-90)

일반 모터와 달리 0도에서 180도 사이의 특정 회전 각도를 세밀하게 고정/지정할 수 있는 모터입니다. 기어 뭉치와 제어회로가 내장되어 로봇 관절이나 주차 바게이트 등에 다양하게 활용됩니다.

• DC 기어드 모터

직류(DC) 전원을 넣으면 한 방향으로 고속 연속 회전하는 일반 모터에 감속 기어를 결합해 속도는 낮추고 힘(토크)을 키운 장치입니다. 주로 스마트 RC카의 구동 바퀴 회전에 쓰입니다.

• 모터드라이버 및 외부 전원

아두이노 출력 핀의 낮은 전류(최대 40mA)로는 모터의 높은 부하를 감당하기 불가능합니다. 따라서 모터드라이버(L298 등)에 외부 고전류 전원을 별도로 연결하고, 아두이노는 신호 제어만 주도하는 형태로 결선합니다.

거리 계산 공식

초음파 전파 비행 시간 계산식

초음파 속도는 약 340m/s(또는 0.034cm/μs)입니다. 소리가 왕복하여 다녀온 마이크로초 단위의 데이터를 활용하여, 단방향 실제 물체까지의 거리를 계산하기 위해 다음 공식을 활용합니다.

distance = ( duration * 0.034 ) / 2

🚩 실습1 : 초음파 거리센서 거리측정

HC-SR04 distance

회로 설명: VCC → 5V, GND → GND, Trig → 6번 디지털 핀(출력), Echo → 5번 디지털 핀(입력)

Ultrasonic.ino 
void setup() {
  Serial.begin(9600);    // 시리얼 통신 속도 설정 (9600bps)
  pinMode(6, OUTPUT);    // Trig 핀 (초음파 발사) → 출력 설정
  pinMode(5, INPUT);     // Echo 핀 (초음파 수신) → 입력 설정
}

void loop() {
  // 초음파 발사
  digitalWrite(6, LOW);   // Trig 핀 초기화
  delayMicroseconds(2);
  digitalWrite(6, HIGH);  // Trig 핀 HIGH → 초음파 발사
  delayMicroseconds(10);
  digitalWrite(6, LOW);   // 트리거 신호 종료

  // Echo 핀으로부터 초음파 반사 시간 측정
  float duration = pulseIn(5, HIGH);  

  // 거리 계산 (단위: cm)
  float distance = ((340.0 * duration) / 2.0) / 10000.0;

  // 시리얼 모니터에 거리 출력
  Serial.println(distance);

  delay(500); // 0.5초마다 반복
}

🚩 실습3 : 서보모터 0도 → 90도 → 180도 → 90도 왕복 동작

Servo Sweep

스위프 제어:

라이브러리를 통해 각도를 지정하고 각 목표 각도 사이사이에 모터가 기계적으로 회전할 수 있는 충분한 물리 시간(delay)을 할당해야 합니다.

servo_sweep.ino 
#include <Servo.h>

Servo myservo;

void setup() {
  myservo.attach(3);     // 서보모터를 3번 핀에 연결
}

void loop() {
  myservo.write(0);      // 0도
  delay(1000);           // 1초 대기

  myservo.write(90);     // 90도
  delay(1000);

  myservo.write(180);    // 180도
  delay(1000);

  myservo.write(90);     // 90도

1. 대입 및 산술 연산자

변수에 값을 저장하거나 센서 수치 계산, 타이머 등에 사용됩니다.

연산자 기호 예시 설명
대입 = speed = 200; 오른쪽 값을 왼쪽 변수에 저장
덧셈 + val = a + 10; 두 값의 합
뺄셈 - remain = maxVal - curVal; 두 값의 차
곱셈 * total = count * 5; 두 값의 곱
나눗셈 / avg = sum / 3; 두 값의 몫
나머지 % step = tick % 4; 나눈 후 나머지 (주기적 패턴 생성 시 활용)

2. 비교(관계) 연산자

if, while 문 등에서 조건을 비교할 때 사용하며, 결과는 참(true/1) 또는 거짓(false/0)입니다.

연산자 기호 예시 설명
같음 == if (sensor == LOW) 두 값이 같으면 참 (= 대입 연산자와의 혼동 주의!)
같지 않음 != if (state != 0) 두 값이 다르면 참
크다 / 작다 >, < if (distance < 10) 크기 비교 (초과/미만)
이상 / 이하 >=, <= if (val >= 255) 크기 비교 (이상/이하)

3. 논리 연산자

여러 센서 조건이나 버튼 입력을 조합할 때 사용합니다.

연산자 기호 예시 설명
논리 AND && if (leftSensor == LOW && rightSensor == LOW) 둘 다 참일 때만 참 (예: 양쪽 센서 모두 장애물 감지 시)
논리 OR || if (frontDist < 10 || backDist < 10) 둘 중 하나라도 참이면 참
논리 NOT ! digitalWrite(ledPin, !digitalRead(ledPin)); 참/거짓을 반전시킴 (토글 스위치 상태 반전 구현 시 활용)

4. 복합 대입 및 증감 연산자

변수의 값을 간결하게 갱신하거나 루프 카운트를 증가시킬 때 사용합니다.

연산자 기호 예시 동일한 표현
증가 ++ count++; count = count + 1;
감소 -- timer--; timer = timer - 1;
복합 덧셈 += speed += 10; speed = speed + 10;
복합 뺄셈 -= speed -= 10; speed = speed - 10;

5. 비트(Bitwise) 연산자 (고급/하드웨어 제어)

포트 직접 제어나 레지스터 설정, 통신 패킷 파싱 시 주로 사용되는 고급 연산 장치입니다.

& (비트 AND)

지정한 비트 필드 중 특정 값만 축출하는 마스크 연산 시 사용

| (비트 OR)

기존 레지스터 값에 영향 없이 특정 위치 비트만 1로 셋업할 때 사용

^ (비트 XOR)

두 비트가 서로 다를 때만 1을 내어, 특정 데이터 비트를 반전시킬 때 사용

~ (비트 NOT)

모든 비트의 0을 1로, 1을 0으로 뒤집어 1의 보수를 계산

<<, >> (비트 시프트)

지정한 비트 칸 수만큼 데이터를 좌/우측으로 이동 (곱하기 2 / 나누기 2 대체 속도 개선법)

핵심 입출력 시스템 함수 정리

1. pinMode(핀번호, 모드)

지정한 디지털 핀의 방향을 결정합니다.

  • OUTPUT: 전류를 밖으로 밀어낼 때 사용합니다. (LED, 모터, 부저)
  • INPUT: 전압 신호를 받아올 때 사용합니다. (일반 센서)
  • INPUT_PULLUP: 내부 풀업 저항을 활성화하여 평소 HIGH, 눌렸을 때 LOW를 받도록 구성합니다. (스위치)
2. digitalWrite(핀번호, 상태값)

디지털 핀으로 출력 신호를 강하게 쏘거나 차단합니다.

  • HIGH: 5V (또는 3.3V) 신호를 핀에 공급하여 소자를 켭니다.
  • LOW: 0V 신호로 내려 전류를 완전히 차단해 소자를 끕니다.

if (sensorValue == LOW) {

조건이 만족되는 동안 중괄호 안의 명령을 계속해서 반복 순회합니다.

🚩 중급 실습1 : IR 적외선 장애물 감지 센서 제어

Infrared Sensor Control

결선 방법:

  • 센서 VCC → 아두이노 5V
  • 센서 GND → 아두이노 GND
  • 센서 OUT (또는 S) → 아두이노 D2 (디지털 입력)
IR_Obstacle_Sensor.ino 
const int sensorPin = 2; // 센서의 S(Signal) 핀을 디지털 2번에 연결
const int ledPin = 13;   // 아두이노 내장 LED (13번)

void setup() {
  pinMode(sensorPin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int sensorValue = digitalRead(sensorPin);

  // 일반적인 적외선 센서는 물체 감지 시 LOW(0)를 출력합니다.
  if (sensorValue == LOW) {
    Serial.println("장애물 감지!");
    digitalWrite(ledPin, HIGH); // 물체가 있으면 내장 LED 켜짐
  } else {
    Serial.println("감지 안 됨");
    digitalWrite(ledPin, LOW);  // 물체가 없으면 내장 LED 꺼짐
  }

  delay(200);
}

🚩 중급 실습2 : IR 장애물 감지 센서로 DC모터 제어하기

IR & DC Motor Control

결선 방법:

  • IR 센서 Signal(S) → 아두이노 D2 핀
  • L9110S A-1A (속도) → D9 핀 (PWM 출력)
  • L9110S A-1B (방향) → D8 핀 (출력)
장애물이 나타나면 사고 방지를 위해 모터를 정지하고, 장애물이 사라지면 다시 200의 속도로 안전 주행을 전개하도록 동작합니다.
IR_DC_Motor_Control.ino 
/*
 * IR 적외선 장애물 감지 센서 & L9110S 모터 드라이버 제어 코드
 * 
 * [핀 연결]
 * - IR 센서 Signal(S) : Digital 2번 핀
 * - L9110S A-1A (속도) : Digital 9번 핀 (PWM 지원)
 * - L9110S A-1B (방향) : Digital 8번 핀
 */

const int sensorPin = 2;  // IR 적외선 센서 신호 핀 (S)
const int motorPinA = 9;  // L9110S A-1A (PWM 속도 제어 핀)
const int motorPinB = 8;  // L9110S A-1B (방향 제어 핀)

// 주행 속도 설정 (0: 정지 ~ 255: 최대 속도)
const int driveSpeed = 200;

void setup() {
  // 핀 모드 설정
  pinMode(sensorPin, INPUT);
  pinMode(motorPinA, OUTPUT);
  pinMode(motorPinB, OUTPUT);

  // 시리얼 모니터 시작 (9600 보드레이트)
  Serial.begin(9600);
  Serial.println("시스템 준비 완료: 주행을 시작합니다.");
}

void loop() {
  // IR 센서 값 읽기 (장애물 감지 시 LOW, 미감지 시 HIGH)
  int obstacle = digitalRead(sensorPin);

  if (obstacle == LOW) {
    // [장애물 감지됨] -> 모터 정지
    digitalWrite(motorPinA, LOW);
    digitalWrite(motorPinB, LOW);
    Serial.println("[경고] 장애물 감지: 모터 정지");
  } else {
    // [장애물 없음] -> 전진 주행
    analogWrite(motorPinA, driveSpeed); // 9번 핀으로 속도 조절
    digitalWrite(motorPinB, LOW);       // 8번 핀 LOW 고정
    Serial.println("[정상] 전방 이상 없음: 모터 주행 중...");
  }

  // 0.05초 대기 (안정적인 센싱 주기)
  delay(50);
}

중급 2차시 주요 장치/개념 설명

스마트폰 웹앱과 무선 직렬(UART) 통신을 수행합니다. 아두이노 SoftwareSerial(3번 RX, 2번 TX) 핀으로 주행 명령 문자(1~7)를 전달받습니다.

아두이노의 낮은 출력 전류를 모터 구동 전력으로 증폭합니다. PWM 신호(D9, D5)로 좌우 바퀴의 정밀 속도 제어와 정역회전(전진/후진)을 조절합니다.

• 2채널 적외선 라인 트레이서 센서

바닥에 적외선을 쏘아 반사되는 양으로 검은색 트랙(LOW)과 흰색 바탕(HIGH)을 판별하여 선을 이탈하지 않고 자율 주행을 구현합니다.

중급 2차시 아두이노 핀 연결 구성표

TX → 아두이노 D3 (RX)

RX → 아두이노 D2 (TX)

전원: VCC(5V), GND 연결

오른쪽(B): B-IA D5, B-IB D4

VCC, GND는 외부전원에 연결, GND는 아두이노 GND에도 연결해줍니다.

오른쪽 센서 OUT → D10

🚩 중급 실습1-2 : 블루투스 연결 모터 구동 테스트

테스트 명령 규칙:

모터 드라이버(L9110S)와 블루투스(HM-10) 통신 연결을 확인하고 바퀴가 정상 회전하는지 점검하는 기초 코드입니다.

  • 1 : 전진 (Forward, 좌우 모터 전진 회전)
  • 0 : 정지 (Stop, 모든 모터 정지)

* 스마트폰 블루투스 앱 또는 아두이노 IDE 시리얼 모니터(9600 Baud)에서 1과 0을 전송해 테스트할 수 있습니다.

팁: 만약 한쪽 바퀴가 반대로 회전한다면 해당 모터의 결선(A-IA, A-IB 또는 B-IA, B-IB) 핀을 서로 맞바꿔 꽂으면 정방향으로 회전합니다.

블루투스를 핸드폰에서 연결할 때, 안드로이드폰은 Arduino Bluetooth Controller, 아이폰은 Bluetooth for arduino 등의 앱을 설치해서 연결하세요.

rccar_motor_bluetooth.ino 
#include <SoftwareSerial.h>

// ==========================================
// HM-10 Bluetooth
// Arduino D3(TX) -> HM-10 RX
// Arduino D2(RX) <- HM-10 TX
// ==========================================
SoftwareSerial bluetooth(3, 2);

// ==========================================
// L9110S Motor
// ==========================================

// A Motor
const int motorA_IA = 9;
const int motorA_IB = 8;

// B Motor
const int motorB_IA = 5;
const int motorB_IB = 4;

// Motor speed (0~255)
const int driveSpeed = 200;


void setup() {

  // Motor pin setting
  pinMode(motorA_IA, OUTPUT);
  pinMode(motorA_IB, OUTPUT);

  pinMode(motorB_IA, OUTPUT);
  pinMode(motorB_IB, OUTPUT);

  // Motor stop
  stopMotors();

  // USB Serial Monitor
  Serial.begin(9600);

  // HM-10
  bluetooth.begin(9600);

  Serial.println("============================");
  Serial.println("HM-10 Bluetooth Test");
  Serial.println("============================");
  Serial.println("Bluetooth : 1 = Forward");
  Serial.println("Bluetooth : 0 = Stop");
  Serial.println("");
  Serial.println("You can also type 1 or 0");
  Serial.println("in Serial Monitor.");
  Serial.println("============================");
}


void loop() {

  // ======================================
  // 1. HM-10 Bluetooth receive
  // ======================================
  if (bluetooth.available()) {

    char command = bluetooth.read();

    Serial.print("[Bluetooth RX] ");
    Serial.print("Character = ");
    Serial.print(command);

    Serial.print(" / ASCII = ");
    Serial.println((int)command);

    controlMotor(command);
  }


  // ======================================
  // 2. Serial Monitor receive
  // ======================================
  if (Serial.available()) {

    char command = Serial.read();

    // Ignore Enter and Line Feed
    if (command == '\r' || command == '\n') {
      return;
    }

    Serial.print("[Serial Monitor RX] ");
    Serial.println(command);

    controlMotor(command);
  }
}


// ==========================================
// Command
// ==========================================
void controlMotor(char command) {

  if (command == '1') {

    Serial.println(">>> FORWARD");

    forward();
  }

  else if (command == '0') {

    Serial.println(">>> STOP");

    stopMotors();
  }

  else {

    Serial.print(">>> Unknown command : ");
    Serial.println(command);
  }
}


// ==========================================
// Forward
// ==========================================
void forward() {

  // Motor A
  analogWrite(motorA_IA, driveSpeed);
  digitalWrite(motorA_IB, LOW);

  // Motor B
  analogWrite(motorB_IA, driveSpeed);
  digitalWrite(motorB_IB, LOW);
}


// ==========================================
// Stop
// ==========================================
void stopMotors() {

  digitalWrite(motorA_IA, LOW);
  digitalWrite(motorA_IB, LOW);

  digitalWrite(motorB_IA, LOW);
  digitalWrite(motorB_IB, LOW);
}

🚩 중급 실습2 : 2채널 센서 라인트레이싱 자율주행 코딩

라인트레이싱 자율 주행 판단 로직:

왼쪽(D11) 오른쪽(D10) 주행 동작
흰색 (HIGH) 흰색 (HIGH) 직진 전진
검정 (LOW) 흰색 (HIGH) 좌회전 (선 복귀)
흰색 (HIGH) 검정 (LOW) 우회전 (선 복귀)
검정 (LOW) 검정 (LOW) 전진 / 교차로 통과

* 라인트레이싱 시에는 정밀한 방향 보정을 위해 일반 주행보다 낮은 속도(약 80~100)를 권장합니다.

LineTracing_Basic.ino 
const int leftSensor = 11;
const int rightSensor = 10;

const int motorA_IA = 9;
const int motorA_IB = 8;
const int motorB_IA = 5;
const int motorB_IB = 4;

const int lineTraceSpeed = 80;

void setup() {
  pinMode(leftSensor, INPUT);
  pinMode(rightSensor, INPUT);
  pinMode(motorA_IA, OUTPUT);
  pinMode(motorA_IB, OUTPUT);
  pinMode(motorB_IA, OUTPUT);
  pinMode(motorB_IB, OUTPUT);
}

void loop() {
  int leftVal = digitalRead(leftSensor);
  int rightVal = digitalRead(rightSensor);

  if (leftVal == LOW && rightVal == HIGH) {
    // 왼쪽 검은색 감지 -> 좌회전 보정
    digitalWrite(motorA_IA, LOW);
    digitalWrite(motorA_IB, LOW);
    analogWrite(motorB_IA, lineTraceSpeed);
    digitalWrite(motorB_IB, LOW);
  } else if (leftVal == HIGH && rightVal == LOW) {
    // 오른쪽 검은색 감지 -> 우회전 보정
    analogWrite(motorA_IA, lineTraceSpeed);
    digitalWrite(motorA_IB, LOW);
    digitalWrite(motorB_IA, LOW);
    digitalWrite(motorB_IB, LOW);
  } else {
    // 직진
    analogWrite(motorA_IA, lineTraceSpeed);
    digitalWrite(motorA_IB, LOW);
    analogWrite(motorB_IA, lineTraceSpeed);
    digitalWrite(motorB_IB, LOW);
  }
  delay(30);
}

  Serial.println("============================");
}


// =========================================================
// 반복 실행
// =========================================================
void loop() {

  // =======================================================
  // HM-10 블루투스 명령 수신
  // =======================================================
  if (bluetooth.available()) {

    char command = bluetooth.read();

    if (command != '\r' && command != '\n') {

      Serial.print("[Bluetooth RX] ");
      Serial.println(command);

      controlCommand(command);
    }
  }


  // =======================================================
  // 시리얼 모니터에서도 테스트 가능
  // =======================================================
  if (Serial.available()) {

    char command = Serial.read();

    if (command != '\r' && command != '\n') {

      Serial.print("[Serial RX] ");
      Serial.println(command);

      controlCommand(command);
    }
  }


  // =======================================================
  // 라인트레이싱 모드 실행
  // =======================================================
  if (lineTracingMode == true) {

    lineTracing();
  }
}


// =========================================================
// 블루투스 명령 처리
// =========================================================
void controlCommand(char command) {

  // =======================================================
  // 라인트레이싱 중에는 7번만 허용
  // =======================================================
  if (lineTracingMode == true) {

    if (command == '7') {

      lineTracingMode = false;

      stopMotors();

      Serial.println("============================");
      Serial.println(">>> LINE TRACING STOP");
      Serial.println(">>> MANUAL CONTROL MODE");
      Serial.println("============================");
    }

    else {

      Serial.println(">>> LINE TRACING MODE");
      Serial.println(">>> Command ignored");
      Serial.println(">>> Press 7 to exit");
    }

    return;
  }


  // =======================================================
  // 일반 블루투스 조작
  // =======================================================
  switch (command) {

    // 1 : 전진
    case '1':

      Serial.println(">>> FORWARD");

      forward();

      break;


    // 2 : 후진
    case '2':

      Serial.println(">>> BACKWARD");

      backward();

      break;


    // 3 : 좌회전
    case '3':

      Serial.println(">>> LEFT");

      turnLeft();

      break;


    // 4 : 우회전
    case '4':

      Serial.println(">>> RIGHT");

      turnRight();

      break;


    // 5 : 정지
    case '5':

      Serial.println(">>> STOP");

      stopMotors();

      break;


    // 6 : 라인트레이싱 시작
    case '6':

      Serial.println("============================");
      Serial.println(">>> LINE TRACING START");
      Serial.println(">>> DRIVE SPEED : 60");
      Serial.println(">>> TURN SPEED  : 150");
      Serial.println(">>> Press 7 to exit");
      Serial.println("============================");

      lineTracingMode = true;

      break;


    // 7 : 일반 모드에서는 정지
    case '7':

      stopMotors();

      Serial.println(">>> MANUAL CONTROL MODE");

      break;


    // 알 수 없는 명령
    default:

      Serial.println(">>> UNKNOWN COMMAND");

      break;
  }
}


// =========================================================
// 라인트레이싱
// =========================================================
void lineTracing() {

  // 센서 값 읽기
  int leftSensorValue =
    digitalRead(leftLineSensor);

  int rightSensorValue =
    digitalRead(rightLineSensor);


  // =======================================================
  // 왼쪽 센서만 검은색
  // → 빠르게 좌회전
  // =======================================================
  if (leftSensorValue == LOW &&
      rightSensorValue == HIGH) {

    lineTurnLeft();

    Serial.println(
      "[LINE] LEFT BLACK -> FAST LEFT"
    );
  }


  // =======================================================
  // 오른쪽 센서만 검은색
  // → 빠르게 우회전
  // =======================================================
  else if (leftSensorValue == HIGH &&
           rightSensorValue == LOW) {

    lineTurnRight();

    Serial.println(
      "[LINE] RIGHT BLACK -> FAST RIGHT"
    );
  }


  // =======================================================
  // 양쪽 모두 흰색
  // → 속도 60으로 천천히 전진
  // =======================================================
  else if (leftSensorValue == HIGH &&
           rightSensorValue == HIGH) {

    lineForward();

    Serial.println(
      "[LINE] WHITE / WHITE -> SLOW FORWARD"
    );
  }


  // =======================================================
  // 양쪽 모두 검은색
  // → 천천히 전진
  // =======================================================
  else {

    lineForward();

    Serial.println(
      "[LINE] BLACK / BLACK -> SLOW FORWARD"
    );
  }


  // 센서 반응 속도
  delay(10);
}

STEP 4 L298N 듀얼 H-Bridge 모터 드라이버 동작 원리 & 진리표

PDF 141p ~ 151p 핵심 이론

왜 모터 드라이버가 꼭 필요할까요?

아두이노 IO 핀의 출력 전류는 최대 40mA에 불과합니다. 반면 RC카 구동에 사용되는 4개의 DC 모터는 회전 시 수백 mA ~ 1A 이상의 강력한 전류를 필요로 합니다. 아두이노 보드에 직접 모터를 연결하면 전력 부족으로 오작동하거나 칩이 타버릴 수 있기 때문에, 외부 전원(배터리)을 모터에 안전하게 공급하고 방향과 속도를 스위칭해주는 L298N 전용 모터 드라이버가 필수적입니다.

H-Bridge 회로의 스위칭 메커니즘

L298N 내부에는 알파벳 'H' 모양으로 배치된 4개의 트랜지스터 스위치가 내장되어 있습니다. 대각선 방향의 스위치 2개씩을 교대로 ON/OFF 함으로써, 모터 양단에 흐르는 전류의 방향을 자유자재로 바꾸어 정회전(전진)과 역회전(후진)을 실현합니다.

L298N 모터 방향 제어 진리표 (Truth Table)

🚗 전진 (SmartCar_Go)
• 오른쪽 모터: IN1 = HIGH, IN2 = LOW
• 왼쪽 모터: IN3 = HIGH, IN4 = LOW
🔙 후진 (SmartCar_Back)
• 오른쪽 모터: IN1 = LOW, IN2 = HIGH
• 왼쪽 모터: IN3 = LOW, IN4 = HIGH
⚖️ 속도 제어 & 직진 보정 (PWM)

ENA, ENB 핀에 analogWrite(pin, 0~255) 값을 전달합니다. 제작 오차로 RC카가 오른쪽으로 치우쳐 달릴 경우, 우측 모터 속도를 올리거나 좌측 모터 속도를 살짝 낮추어 완벽한 직진 주행을 맞출 수 있습니다!

예제 2

6_Motor_driver.ino (L298N 전진 3초 / 후진 3초 주행 테스트)

// =========================================================
// [에듀이노] 4휠 스마트 RC카 - 6_Motor_driver
// L298N 모터 드라이버를 이용한 4휠 전진/후진 구동 예제
// =========================================================

int RightMotor_E_pin = 5;       // 오른쪽 모터 속도 제어(PWM) -> D5
int RightMotor_1_pin = 8;       // 오른쪽 모터 정/역 방향 제어 IN1 -> D8
int RightMotor_2_pin = 9;       // 오른쪽 모터 정/역 방향 제어 IN2 -> D9
int LeftMotor_3_pin  = 10;      // 왼쪽 모터 정/역 방향 제어 IN3 -> D10
int LeftMotor_4_pin  = 11;      // 왼쪽 모터 정/역 방향 제어 IN4 -> D11
int LeftMotor_E_pin  = 6;       // 왼쪽 모터 속도 제어(PWM) -> D6

// 함수 원형 선언
void SmartCar_Go();
void SmartCar_Back();

// 좌우 모터 기본 속도 (0 ~ 255 범위, 153은 약 60% 출력)
int L_MotorSpeed = 153;        // 왼쪽 모터 속도
int R_MotorSpeed = 153;        // 오른쪽 모터 속도

void setup() {
  Serial.begin(9600);
  
  // 모든 모터 제어 핀을 출력(OUTPUT) 모드로 설정
  pinMode(RightMotor_E_pin, OUTPUT);        
  pinMode(RightMotor_1_pin, OUTPUT);
  pinMode(RightMotor_2_pin, OUTPUT);
  pinMode(LeftMotor_3_pin, OUTPUT);
  pinMode(LeftMotor_4_pin, OUTPUT);
  pinMode(LeftMotor_E_pin, OUTPUT);

  Serial.println("4WD Smart Car Motor Driver Ready!");
}

void loop() {
  // 1. 3초간 전진 주행
  SmartCar_Go();
  delay(3000);

  // 2. 3초간 후진 주행
  SmartCar_Back();
  delay(3000);
}

// ---------------------------------------------------------
// 스마트카 전진 함수 (모든 바퀴 정회전)
// ---------------------------------------------------------
void SmartCar_Go() {
  Serial.println("Forward (전진)");
  // 오른쪽 모터 정회전
  digitalWrite(RightMotor_1_pin, HIGH);
  digitalWrite(RightMotor_2_pin, LOW);
  // 왼쪽 모터 정회전
  digitalWrite(LeftMotor_3_pin, HIGH);
  digitalWrite(LeftMotor_4_pin, LOW);
  
  // 좌우 속도 인가 (PWM)
  analogWrite(RightMotor_E_pin, R_MotorSpeed);
  analogWrite(LeftMotor_E_pin, L_MotorSpeed);
}

// ---------------------------------------------------------
// 스마트카 후진 함수 (모든 바퀴 역회전)
// ---------------------------------------------------------
void SmartCar_Back() {
  Serial.println("Backward (후진)");
  // 오른쪽 모터 역회전
  digitalWrite(RightMotor_1_pin, LOW);
  digitalWrite(RightMotor_2_pin, HIGH);
  // 왼쪽 모터 역회전
  digitalWrite(LeftMotor_3_pin, LOW);
  digitalWrite(LeftMotor_4_pin, HIGH);
  
  // 좌우 속도 인가 (PWM)
  analogWrite(RightMotor_E_pin, R_MotorSpeed);
  analogWrite(LeftMotor_E_pin, L_MotorSpeed);
}
예제 3

Line_sensor_test.ino (라인트레이서 센서 3개 동작 확인 코드)

주행 코드를 올리기 전에 라인트레이서 센서 3개(A5, A4, A3)가 정상적으로 값을 읽는지 먼저 확인합니다. 모터는 전혀 움직이지 않으므로 배터리 전원 없이 USB만 연결한 상태에서 테스트할 수 있습니다. 

void setup() {
  Serial.begin(9600);
}

void loop() {
  Serial.print("L(A5)="); Serial.print(digitalRead(A5));
  Serial.print("  C(A4)="); Serial.print(digitalRead(A4));
  Serial.print("  R(A3)="); Serial.print(digitalRead(A3));
  Serial.print("   analog: ");
  Serial.print(analogRead(A5)); Serial.print(", ");
  Serial.print(analogRead(A4)); Serial.print(", ");
  Serial.println(analogRead(A3));
  delay(200);
}
테스트 순서
  1. 위 코드를 업로드하고 시리얼 모니터를 열어 속도를 9600 baud로 맞춥니다.
  2. 0.2초마다 L / C / R 값이 한 줄씩 출력되는지 확인합니다.
  3. 흰 종이 위에 차를 올려 세 센서의 값을 읽고, 이어서 검은색 테이프(라인) 위로 센서를 하나씩 옮기며 값이 바뀌는지 확인합니다.
  4. 왼쪽 센서를 라인에 올렸을 때 L(A5) 값만 바뀌면 배선 순서가 맞는 것입니다. 다른 자리의 값이 바뀌면 A3~A5 결선을 서로 바꿔 꽂습니다.
출력값 읽는 법
  • digitalRead (0 / 1): 주행 코드가 실제로 사용하는 값입니다. 일반적으로 검은색 라인 = 0(LOW), 흰색 바탕 = 1(HIGH)이지만 센서 모듈에 따라 반대일 수 있으니 실제 출력으로 확인하세요.
  • analogRead (0 ~ 1023): 센서가 받는 반사광의 세기입니다. 흰색과 검은색에서 값 차이가 크게 벌어져야 정상이며, 차이가 작으면 센서 높이(바닥에서 약 1 cm)나 조절 나사(가변저항)를 돌려 감도를 맞춥니다.
  • 값이 전혀 안 바뀌거나 항상 같은 값: 해당 센서의 S 신호선, VCC, GND 배선을 다시 확인합니다. 센서 뒷면 LED가 라인 위에서 켜지거나 꺼지는지도 함께 보면 좋습니다.

💡 세 센서 모두 흰색과 검은색을 확실히 구분하면 라인트레이서 주행 코드를 업로드할 준비가 된 것입니다.

모터 주행 테스트 시 안전 필수 수칙!

조립 & 주행 자주 묻는 질문 (Troubleshooting)

Q1. 전진을 시켰는데 좌우 바퀴가 서로 반대로 돌거나 뒤로 가요!

A. 모터 단자 결선 시 (+)선과 (-)선이 바뀌었을 때 발생합니다. 해당 바퀴의 L298N 단자대 나사를 풀고 빨간선과 검은선 위치를 서로 맞바꾸어 조여주거나, 아두이노 코드의 SmartCar_Go() 함수에서 HIGH와 LOW 값을 서로 반대로 변경해주면 깔끔하게 해결됩니다.

Q2. RC카가 똑바로 가지 않고 자꾸 한쪽(오른쪽 또는 왼쪽)으로 휘어요!

A. 모터의 기어 및 물리적 특성상 좌우 회전 속도에 미세한 차이가 발생할 수 있습니다. 오른쪽으로 휜다면 오른쪽 바퀴가 느린 것이므로, 코드 상단의 R_MotorSpeed 값을 153에서 170~180 정도로 높여주거나, L_MotorSpeed를 140 정도로 낮추어 주행 테스트를 반복하며 중심을 맞춥니다.

Q3. 코드를 업로드했는데 바퀴가 전혀 돌지 않고 삐~ 소리만 나요!

A. 모터는 USB 전원만으로는 구동되지 않습니다. AA 건전지 6개가 배터리 홀더에 정상적으로 장착되어 있는지 확인하고, L298N 전원 단자대의 나사가 단단히 조여져 있는지 점검하세요. 또한 PWM 속도 값이 너무 낮으면(예: 100 이하) 모터가 돌지 못하므로 속도 변수 값을 150 이상으로 지정해 보세요.

이름 바꾸는 순서
  1. 모듈을 공통 배선대로 연결하고 배터리는 끈 채 USB만 연결합니다.
  2. 폰과 연결되어 있으면 안 됩니다. 모듈 LED가 깜빡이는 상태(미연결)인지 확인합니다. 연결 중이면 폰의 앱·웹 조종기에서 연결을 끊습니다.
  3. 아래 BT_rename.ino의 NEW_NAME을 자기 번호(예: JGH07)로 바꾸고 업로드합니다.
  4. 시리얼 모니터(9600 baud)를 엽니다. >> AT → << OK, >> AT+NAMEJGH07 → << OK... 가 보이면 성공입니다.
  5. USB를 뽑았다 다시 꽂아(모듈 전원 재시작) 폰에서 새 이름이 검색되는지 확인합니다.
  6. 이름이 바뀌었으면 실습 A 또는 B의 코드를 업로드합니다. 이름은 모듈에 저장되므로 매번 다시 할 필요가 없습니다.

BT_rename.ino

NEW_NAME만 바꿔 업로드 · AT 응답을 보고 줄바꿈·명령 형식을 자동 선택 · 업로드 후에는 AT 명령 브리지로 동작

다운로드
/* BT_rename.ino - 블루투스 모듈 이름 바꾸기 (HC-06 / HM-10 / BT05 공용)
 *
 * 한 교실에서 30대가 함께 쓰면 폰에서 같은 이름이 30개 보여 자기 차를 찾을 수 없습니다.
 * 아래 NEW_NAME 을 자기 번호로 바꾸고 업로드하면 자동으로 AT 명령을 보내 이름을 바꿉니다.
 *
 * 사용 순서
 *   1. 모듈을 쉴드에 연결 (VCC->V3, GND->G3, TXD->S3, RXD->S4) 하고 배터리는 끕니다.
 *   2. 폰과 연결되어 있지 않은 상태(모듈 LED 깜빡임)여야 AT 명령이 통합니다.
 *   3. NEW_NAME 수정 -> 업로드 -> 시리얼 모니터(9600) 를 엽니다.
 *   4. "OK" 응답이 보이면 모듈 전원을 껐다 켠 뒤 폰에서 새 이름을 검색합니다.
 *
 * 업로드 후에는 시리얼 모니터에 입력한 글자가 모듈로 그대로 전달되므로
 * AT 명령을 직접 입력해 볼 수도 있습니다. (줄바꿈 설정은 아래 표 참고)
 */

#include <SoftwareSerial.h>

// ===================== 여기만 바꾸세요 =====================
const char* NEW_NAME = "JGH01";        // 자기 번호로! 예) JGH01 ~ JGH30 (영문/숫자, 12자 이내)
// ==========================================================

#define BT_RXD 3                        // 아두이노 3번핀 = RX (모듈 TXD 연결)
#define BT_TXD 4                        // 아두이노 4번핀 = TX (모듈 RXD 연결)
SoftwareSerial bluetooth(BT_RXD, BT_TXD);

bool useCRLF = false;                   // 모듈이 줄바꿈(\r\n)을 요구하는지 자동 판별 결과

// AT 명령을 보내고 응답을 1.5초 동안 모아서 돌려줍니다
String sendAT(const char* cmd) {
  while (bluetooth.available()) bluetooth.read();   // 이전 응답 찌꺼기 비우기
  Serial.print(">> ");
  Serial.println(cmd);
  bluetooth.print(cmd);
  if (useCRLF) bluetooth.print("\r\n");

  String resp = "";
  unsigned long t = millis();
  while (millis() - t < 1500) {
    while (bluetooth.available()) {
      char c = bluetooth.read();
      resp += c;
    }
  }
  resp.trim();
  Serial.print("<< ");
  Serial.println(resp.length() ? resp : "(응답 없음)");
  return resp;
}

void setup() {
  Serial.begin(9600);
  bluetooth.begin(9600);
  delay(1500);                          // 모듈 부팅 대기
  Serial.println("===== Bluetooth rename =====");
  Serial.print("새 이름: ");
  Serial.println(NEW_NAME);

  // 1) 줄바꿈 없이 AT -> HC-06(구형), 정품 HM-10 은 여기서 OK
  useCRLF = false;
  String r = sendAT("AT");
  if (r.indexOf("OK") < 0) {
    // 2) 줄바꿈 붙여서 AT -> BT05 등 HM-10 호환품, 신형 HC-06 은 여기서 OK
    useCRLF = true;
    r = sendAT("AT");
  }
  if (r.indexOf("OK") < 0) {
    Serial.println("!! 모듈이 응답하지 않습니다. 폰 연결을 끊고(LED 깜빡임), TXD->S3 / RXD->S4 배선을 확인한 뒤 리셋 버튼을 누르세요.");
    return;
  }

  // 3) 이름 변경: AT+NAMExxx 먼저, 안 되면 AT+NAME=xxx 형식으로 재시도
  String cmd = String("AT+NAME") + NEW_NAME;
  r = sendAT(cmd.c_str());
  if (r.indexOf("OK") < 0) {
    cmd = String("AT+NAME=") + NEW_NAME;
    r = sendAT(cmd.c_str());
  }

  if (r.indexOf("OK") >= 0) {
    sendAT("AT+RESET");                 // HM-10 계열은 재시작해야 새 이름이 보입니다 (HC-06 은 무시)
    Serial.println("===== 완료! 모듈 전원을 껐다 켠 뒤 폰에서 새 이름을 검색하세요 =====");
  } else {
    Serial.println("!! 이름 변경 실패. 시리얼 모니터에서 AT 명령을 직접 입력해 보세요.");
  }
}

// 업로드 후에는 시리얼 모니터 <-> 모듈 브리지로 동작합니다 (11_Bluetooth.ino 와 같음)
void loop() {
  if (bluetooth.available()) Serial.write(bluetooth.read());
  if (Serial.available())    bluetooth.write(Serial.read());
}
이럴 때는 점검하세요
  • AT에 "(응답 없음)"만 나옴: 폰이 모듈에 연결된 상태(LED 계속 켜짐)이면 AT 명령이 통하지 않습니다. 연결을 끊고 아두이노 리셋 버튼을 누르세요. 그래도 안 되면 TXD→S3, RXD→S4가 바뀌지 않았는지 확인합니다.
  • OK는 나오는데 폰에서 옛 이름이 보임: 모듈 전원을 껐다 켜야 새 이름으로 광고합니다. 안드로이드는 설정의 블루투스 목록에서 기존 HC-06 페어링을 삭제한 뒤 다시 검색합니다.
  • 이름에 한글·공백을 쓰고 싶음: 모듈 종류에 따라 깨지거나 거부됩니다. 영문과 숫자만 사용하세요.

웹 조종기 숫자(1~5)와 원본 문자(g/b/l/r/s/q/w)를 모두 인식 · 12번 원본을 바탕으로 수정

다운로드
/* 12_RC_CAR_Bluetooth.ino (에듀이노 SmartCar 기본예제 8) 를 바탕으로
 * HM-10(BLE) + 스마트폰 웹 조종기 실습용으로 수정한 버전입니다.
 *
 * 웹 조종기(https://suguri123.github.io/RCcar_blu_jhg/)는 숫자 문자를 보냅니다.
 *   '1' 전진   '2' 후진   '3' 우회전   '4' 좌회전   '5' 정지 (버튼을 놓으면 자동 전송)
 *   '6' '7' 은 라인트레이싱용 명령이므로 이 코드에서는 무시합니다.
 *
 * 원본의 문자 명령도 그대로 동작합니다.
 *   'g' 전진   'b' 후진   'l' 좌회전   'r' 우회전   's' 정지   'q' 제자리 좌회전   'w' 제자리 우회전
 *
 * 배선 (센서 쉴드 V5.0)
 *   HM-10 VCC -> V3 (5V)      HM-10 GND -> G3
 *   HM-10 TXD -> S3 (D3, 아두이노 RX)
 *   HM-10 RXD -> S4 (D4, 아두이노 TX)
 */

#include <SoftwareSerial.h>                            // 가상 시리얼 통신을 위한 라이브러리 선언

#define BT_RXD 3                                       // 아두이노 3번핀 = RX (모듈 TXD 연결)
#define BT_TXD 4                                       // 아두이노 4번핀 = TX (모듈 RXD 연결)

SoftwareSerial bluetooth(BT_RXD, BT_TXD);              // 블루투스 통신을 위한 설정

int RightMotor_E_pin = 5;                              // 오른쪽 모터의 Enable & PWM
int LeftMotor_E_pin = 6;                               // 왼쪽 모터의 Enable & PWM
int RightMotor_1_pin = 8;                              // 오른쪽 모터 제어선 IN1
int RightMotor_2_pin = 9;                              // 오른쪽 모터 제어선 IN2
int LeftMotor_3_pin = 10;                              // 왼쪽 모터 제어선 IN3
int LeftMotor_4_pin = 11;                              // 왼쪽 모터 제어선 IN4

int L_MotorSpeed = 185;                                // 왼쪽 모터 속도
int R_MotorSpeed = 160;                                // 오른쪽 모터 속도

int R_Motor = HIGH;                                    // 시작 방향은 전진으로 둡니다
int L_Motor = HIGH;
int mode = 3;                                          // 시작 모드 3 = 정지

void setup() {
  pinMode(RightMotor_E_pin, OUTPUT);                   // 출력모드로 설정
  pinMode(RightMotor_1_pin, OUTPUT);
  pinMode(RightMotor_2_pin, OUTPUT);
  pinMode(LeftMotor_3_pin, OUTPUT);
  pinMode(LeftMotor_4_pin, OUTPUT);
  pinMode(LeftMotor_E_pin, OUTPUT);

  Serial.begin(9600);
  bluetooth.begin(9600);

  Serial.println("HM-10 RC Car Ready (1:Go 2:Back 3:Right 4:Left 5:Stop)");
}

void loop() {
  if (bluetooth.available()) {
    char Blue_Val = bluetooth.read();
    Serial.print(Blue_Val);                            // 수신 문자를 시리얼 모니터에 표시
    control_SmartCar(Blue_Val);

    if (mode == 0) {
      motor_role(R_Motor, L_Motor);
    }
    else if (mode == 1) {
      Right_role(R_Motor, L_Motor);
    }
    else if (mode == 2) {
      Left_role(R_Motor, L_Motor);
    }
    else if (mode == 4) {
      left_rotation(R_Motor, L_Motor);
    }
    else if (mode == 5) {
      right_rotation(R_Motor, L_Motor);
    }
    else {
      analogWrite(RightMotor_E_pin, 0);
      analogWrite(LeftMotor_E_pin, 0);
    }
  }
}

void control_SmartCar(char Blue_val) {
  if (Blue_val == 'g' || Blue_val == '1') {            // 전진
    R_Motor = HIGH; L_Motor = HIGH; mode = 0;
  }
  else if (Blue_val == 'b' || Blue_val == '2') {       // 후진
    R_Motor = LOW; L_Motor = LOW; mode = 0;
  }
  else if (Blue_val == '3') {                          // 웹 조종기 우회전 (전진 방향으로 회전)
    R_Motor = HIGH; L_Motor = HIGH; mode = 1;
  }
  else if (Blue_val == '4') {                          // 웹 조종기 좌회전 (전진 방향으로 회전)
    R_Motor = HIGH; L_Motor = HIGH; mode = 2;
  }
  else if (Blue_val == 'r') {                          // 원본 우회전 (직전 전진/후진 방향 유지)
    mode = 1;
  }
  else if (Blue_val == 'l') {                          // 원본 좌회전 (직전 전진/후진 방향 유지)
    mode = 2;
  }
  else if (Blue_val == 's' || Blue_val == '5') {       // 정지
    R_Motor = HIGH; L_Motor = HIGH; mode = 3;
  }
  else if (Blue_val == 'q') {                          // 제자리 좌회전
    mode = 4;
  }
  else if (Blue_val == 'w') {                          // 제자리 우회전
    mode = 5;
  }
  else {                                               // '6', '7', 줄바꿈 등은 무시
  }
}

void motor_role(int R_motor, int L_motor) {
  digitalWrite(RightMotor_1_pin, R_motor);
  digitalWrite(RightMotor_2_pin, !R_motor);
  digitalWrite(LeftMotor_3_pin, L_motor);
  digitalWrite(LeftMotor_4_pin, !L_motor);

  analogWrite(RightMotor_E_pin, R_MotorSpeed);         // 우측 모터 속도값
  analogWrite(LeftMotor_E_pin, L_MotorSpeed);          // 좌측 모터 속도값
}

void Right_role(int R_motor, int L_motor) {
  digitalWrite(RightMotor_1_pin, R_motor);
  digitalWrite(RightMotor_2_pin, !R_motor);
  digitalWrite(LeftMotor_3_pin, L_motor);
  digitalWrite(LeftMotor_4_pin, !L_motor);

  analogWrite(RightMotor_E_pin, max(R_MotorSpeed * 0.4, 90));   // 우측 모터 속도값
  analogWrite(LeftMotor_E_pin, 255);                             // 좌측 모터 속도값
}

void Left_role(int R_motor, int L_motor) {
  digitalWrite(RightMotor_1_pin, R_motor);
  digitalWrite(RightMotor_2_pin, !R_motor);
  digitalWrite(LeftMotor_3_pin, L_motor);
  digitalWrite(LeftMotor_4_pin, !L_motor);

  analogWrite(RightMotor_E_pin, 255);                            // 우측 모터 속도값
  analogWrite(LeftMotor_E_pin, max(L_MotorSpeed * 0.4, 90));    // 좌측 모터 속도값
}

void left_rotation(int R_motor, int L_motor) {
  digitalWrite(RightMotor_1_pin, HIGH);
  digitalWrite(RightMotor_2_pin, LOW);
  digitalWrite(LeftMotor_3_pin, LOW);
  digitalWrite(LeftMotor_4_pin, HIGH);

  analogWrite(RightMotor_E_pin, R_MotorSpeed);         // 우측 모터 속도값
  analogWrite(LeftMotor_E_pin, L_MotorSpeed);          // 좌측 모터 속도값
}

void right_rotation(int R_motor, int L_motor) {
  digitalWrite(RightMotor_1_pin, LOW);
  digitalWrite(RightMotor_2_pin, HIGH);
  digitalWrite(LeftMotor_3_pin, HIGH);
  digitalWrite(LeftMotor_4_pin, LOW);

  analogWrite(RightMotor_E_pin, R_MotorSpeed);         // 우측 모터 속도값
  analogWrite(LeftMotor_E_pin, L_MotorSpeed);          // 좌측 모터 속도값
}

제작사 최종 코드의 기본 설정

왼쪽 속도는 185, 오른쪽 속도는 160이며 시작 모드는 3(정지)입니다. 모터 핀은 기존 실습과 동일하게 ENA=D5, ENB=D6, IN1~IN4=D8~D11을 사용합니다.

l / r은 직전 전진·후진 방향을 유지하며 좌우 속도 차이로 회전합니다. q / w는 양쪽 모터를 서로 반대 방향으로 구동해 제자리 회전합니다.

  1. 바퀴를 띄운 상태에서 g → s → b → s를 보내 전진·정지·후진부터 확인합니다.
  2. g로 전진 방향을 설정한 뒤 l / r 회전을 확인하고 s로 멈춥니다.
  3. q / w로 제자리 회전을 시험하고 각 동작 뒤 s를 보냅니다.
  4. 시리얼 모니터에서 수신 문자와 실제 바퀴 동작을 비교한 뒤 넓고 평평한 바닥에서 주행합니다.

앱의 정지 버튼은 반드시 s로 설정하세요

이 원본은 명령이 없으면 마지막 주행 상태를 유지합니다. 버튼을 놓거나 블루투스 연결이 끊겨도 자동 정지하지 않습니다. 앱에서 버튼을 놓을 때 정지시키려면 버튼 해제 시 s를 전송하도록 설정하세요.

실습 중 자주 묻는 질문

Q. 리모컨 코드에서 IRrecv 또는 decode_results 관련 오류가 나요.

최신 버전이 있어도 이 수업에서는 IRremote 2.6.0을 선택해 설치하고 다시 컴파일하세요. IRremote.h: No such file or directory 오류는 필요한 헤더를 찾지 못한 상태입니다. 설치 후에도 오류가 남으면 IRremote의 설치 버전과 IDE가 선택한 라이브러리 경로를 확인하세요.

Q. 시리얼에서 Wrong command가 함께 출력돼요.

소문자 g / b / s를 한 글자씩 보내고 줄바꿈을 없음으로 설정하세요. 줄바꿈 문자도 입력으로 처리될 수 있습니다.

Q. 라인을 따라가지 않고 반대로 돌아요.

차량 전방 기준 L=A5, C=A4, R=A3인지 확인하세요. 검정·흰색에서 읽은 실제 값을 조건표와 비교한 뒤, 바퀴 방향과 모터 배선을 점검합니다.

Q. 장애물이 있는데도 회피 방향이 이상해요.

서보 90° 정면, 30°·150°에서 바라보는 방향, 바퀴 전후진을 각각 확인하세요. 원본은 Ult_30이 더 크면 좌회전을 선택하므로 브라켓 방향이 예제와 맞아야 합니다.

Q. 회전이 너무 크거나 속도가 빨라요.

좌우 기본 속도 153에서 시작해 동일한 조건으로 비교하세요. 장애물 회피의 0.8초 회전 시간과 모터 속도를 한 번에 하나씩 바꾸고 결과를 기록합니다.
