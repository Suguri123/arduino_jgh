🚦 Arduino Uno 5-in-1 통합 제어 & 업로더

단 한 번의 업로드로 5대 기능(신호등, 물결, 숨쉬기, 주사위, 수신기)을 웹에서 실시간 제어

가상 시뮬레이터 동작 중

⚡ 아두이노에 5-in-1 펌웨어 업로드 (1회 필수)

한 번만 업로드해 두면, 코드 수정 없이 웹사이트에서 버튼만 눌러 모든 기능을 조종할 수 있습니다.

🖥️ 하드웨어 모듈 실시간 상태

TRAFFIC LIGHT MODULE
ARDUINO UNO (R:9, Y:10, G:11)
빨강 (R) PIN 9
노랑 (Y) PIN 10
초록 (G) PIN 11
현재 동작 모드 대기 중 (IDLE)
RED (D9) 0
YELLOW (D10) 0
GREEN (D11) 0
💡 실제 아두이노 보드와 웹 화면의 LED가 실시간 동기화됩니다.

🚦 신호등 모드 (T 명령)

초록 4초 ➔ 노랑 1초 ➔ 빨강 2초 점등 + 마지막 1초 빠르게 깜빡임

4초
1. 초록불 ON
1초
2. 노랑불 ON
3초
3. 빨강불 (2s+1s 깜빡)

🌊 물결 효과 모드 (W 명령)

빨강 ➔ 노랑 ➔ 초록 순서로 0.2초씩 차례대로 켜졌다 꺼지는 물결 애니메이션

🫁 숨쉬기 모드 (B 명령)

PWM을 통해 세 LED가 호흡하듯 천천히 밝아졌다 어두워집니다.

🎲 불빛 주사위 모드 (D 명령)

세 LED 중 무작위(Random)로 하나만 1초마다 켜지는 행운의 주사위

📡 시리얼 LED 수신기 (0~5 키패드)

숫자 버튼을 누르면 실제 아두이노로 전송되어 지정된 LED가 즉시 켜집니다.

💻 시리얼 모니터 (9600 Baud)

[SYS] 시스템 준비 완료. 상단 '아두이노 보드 연결' 후 원하는 기능을 테스트해 보세요.

⚡ 웹 브라우저 원클릭 펌웨어 업로드

Chrome 또는 Edge 브라우저의 Web Serial을 통해 아두이노 Uno에 5-in-1 통합 펌웨어(all_in_one.ino.hex)를 직접 플래시합니다.

업로드 준비 완료 0%

💻 upload.bat 원클릭 실행 안내
